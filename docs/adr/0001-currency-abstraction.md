# ADR 0001: Абстракция валюты

## Status
Proposed

## Context
Сейчас "руб." захардкожен в UI-строках и, вероятно, в форматировании сумм.
При добавлении других валют это потребует правок во множестве мест.

## Decision (черновик)
Ввести Currency как доменную сущность:
- поле валюты в настройках,
- единая функция форматирования суммы,
- убрать "руб." из UI-строк, оставить как форматируемый суффикс.

## Consequences
- Требует миграции настроек.
- Требует ревизии всех мест, где выводится сумма.
- Не входит в релиз 1.4, планируется в 1.5.

## Out of scope
- Мультивалютные расчёты.
- Курсы валют.
