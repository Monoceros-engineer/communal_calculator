# Калькулятор коммунальных платежей

Версия 1.0

## Описание

Приложение для расчёта коммунальных платежей с поддержкой:
- Произвольного набора услуг (по счётчику и фиксированных)
- Настраиваемых тарифов и комиссии банка
- Сохранения истории расчетов и начальных показаний счётчиков
- Удобного первого запуска с туториалом и подсказками

## Требования

- Windows (скомпилировано в .exe)
- Python 3.12+ (только для разработки)

## Установка и запуск

1. Скачайте файл `CommunalCalculator.exe` из релиза.
2. Поместите его в отдельную папку (при создании файлы конфигурации будут лежать рядом).
3. Запустите `CommunalCalculator.exe`.

## Первый запуск

При первом включении программа покажет туториал, затем откроет окно управления услугами. Добавьте необходимые услуги (газ, свет, вода, интернет, мусор и др.), указав:
- Тип услуги (по счётчику / фиксированная)
- Тариф и комиссию (в %)
- Для услуг по счётчику – начальные показания

После нажатия «Готово» программа перезапустится (это нормально), и вы увидите главное окно. Теперь можно вводить текущие показания и рассчитывать сумму к оплате.

## Использование

- **Главное окно:** введите показания для услуг по счётчику (если поле обязательно, иначе пропустите), поставьте галочку "Комиссия", если банк берёт процент. Нажмите «Рассчитать».
- **Настройки:** изменить тарифы, комиссию, вернуться к начальным значениям, управлять услугами (добавить/удалить/отключить).
- **История:** после расчёта можно сохранить новые показания как начальные для следующего месяца (они также запишутся в файл истории `readings_history.json`).

## Особенности

- Дробные числа можно вводить как с точкой, так и с запятой (например, `123,45` или `123.45`).
- Все настройки хранятся в файле `calculator_config.json` (при необходимости можно отредактировать вручную).
- История расчётов сохраняется в `readings_history.json`.

## Сборка из исходников (для разработчиков)

1. Установите Python 3.12 или выше.
2. Установите зависимости: `pip install pyinstaller`
3. Клонируйте репозиторий.
4. Запустите сборку: `pyinstaller --onefile --windowed --name="CommunalCalculator" main.py`
5. Готовый `.exe` будет в папке `dist`.
